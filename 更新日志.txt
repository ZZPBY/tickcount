1.0.7
----------------------------------------

本版变化

✨ 列表分成两段：还在前面的按所选顺序排在最上面，已经过去的收在「已过去」下面
✨ 长按一张卡片，可以直接置顶、编辑或删除，不必先进详情页
✨ 新增第二个桌面小组件「清单」：接下来几条一行一个，点哪一条就打开哪一条
✨ 导出加密时会让你把密码输两遍，右边的小眼睛可以查看输入的内容，免得存下一份永远打不开的备份
✨ 导入方式那里会先告诉你会新增几条、覆盖几条

🔄 小组件上也能看到具体时间了：日期那行会带上时刻，像「2026年10月22日 13:30」，窄排版挪到天数后面
🔄 「清单」小组件的每一行同样带上时间，写成「今天 09:30」，不再只看得到天数
🔄 添加「单个」小组件时，选事件的那个列表里也显示时间，不会把同名的两条挑混
🔄 「清单」小组件的几行会撑满整个组件，下面不再留一块空白
🔄 原来的小组件改名叫「单个」，点它会直接打开它显示的那条倒数日，而不是只打开应用
🔄 顶部标题栏不再压在状态栏下：菜单、名字和右上角按钮都退到系统图标下面
🔄 导入备份改为先验密码，再问「覆盖」还是「合并」；密码错了就在输入框下面提示，改完直接重试，不用重选文件
🔄 导入方式里的「替换全部」改叫「覆盖」，英文也从 Replace everything 改成 Overwrite，行为不变
🔄 侧边栏的「语言」挪到最下面单独一行，六个入口的顺序不变
🔄 系统字体调大时，标题栏、侧边栏和卡片跟着长高，不再把文字挤掉

🔧 使用：长按一张卡片可以直接置顶、编辑或删除；桌面长按空白 → 添加小组件，现在有「单个」和「清单」两种

1.0.6
----------------------------------------

本版变化

✨ 数据管理：把全部倒数日，以及外观、排序和语言设置导出成一个备份文件，文件存到哪由你选
✨ 导入备份：读回备份时可以选择「替换全部」或「合并」；合并保留现有数据，同一个倒数日以文件里的为准

🔧 密码无法找回：这个应用不联网、没有账号，忘记密码文件就永远打不开，所以加密默认关闭

📦 安装：下载 TickCount-1.0.6.apk，直接安装即可
🔧 使用：侧边栏 → 数据管理 → 导出备份 / 导入备份

1.0.5
----------------------------------------

本版变化

✨ 侧边栏导航：左上角的菜单按钮打开一个占半个屏幕的侧边栏，主页、日历、外观与显示、语言、更新日志、项目介绍都在里面
✨ 主页改成列表：一个倒数日一张圆角卡片，左边是名字、标签和日期，右边还剩多少天
✨ 搜索：列表上方一个搜索框，框内可切换按名字（含标签）、日期或时间筛选
✨ 排序：列表右上角的排序按钮，可按设定时间升序、设定时间降序，或按添加时间（新的在前）
✨ 置顶：倒数日详情里打开「置顶」，它就一直排在列表最上面，不受排序方式影响
✨ 日历：点一天，那天的倒数日就列在月历下方，同样能搜索和排序；右上角的「+」在那天新建
✨ 倒数日详情：点一张卡片进入它自己的画面，年月日时分秒完整拆分，加上日期、时间和标签
✨ 自定义颜色：每个倒数日可以有自己的颜色，在编辑窗口里用色相条调；不指定就用主题色
✨ 主题：白、黑、蓝、绿四种预设，也能自己调一个，页面和卡片都跟着变
✨ 语言切换：侧边栏里可以手动选中文或 English，项目介绍也跟着换
✨ 项目介绍：大图标、项目简介、隐私说明，以及可复制、可跳转的 GitHub 地址
🔄 同一天可以有多个倒数日了，旧数据自动迁移，不会丢
🔄 顶部的「关于」和「更新日志」并入了侧边栏，顶栏腾出来给菜单和新建
🔧 仍然不需要任何权限、不联网、无统计

📦 安装：下载 TickCount-1.0.5.apk，直接安装即可
🔧 使用：主页右上角「+」新建倒数日；左上角菜单里在主页、日历、外观与显示、语言和项目介绍之间切换
