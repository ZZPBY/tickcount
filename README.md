# TickCount

[![Build](https://github.com/ZZPBY/tickcount/actions/workflows/android.yml/badge.svg)](https://github.com/ZZPBY/tickcount/actions/workflows/android.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一个极简、纯离线的安卓倒数日日历。在日历上点一天、起个名字，就能看到离那一天还有多久，
或者已经过去了多久。

## 功能

- **侧边栏** —— 点左上角菜单打开半个屏幕的抽屉：主页、日历，外观与显示、数据管理，更新日志、
  项目介绍；「语言」单独在最下面一行。
- **倒数日列表** —— 一条一张卡片：左边是超大号的天数，右边是名称、标签和日期（填了时间就
  一起显示）。已经过去的收在列表最下面，用「已过去」隔开。
- **置顶与排序** —— 置顶的不受排序影响，始终在最前；排序可选用按日期近的在前、远的在前，
  或按添加时间新的在前，选择会记住。它只管还没过去的那段。
- **搜索与筛选** —— 列表上方一个搜索框，右侧可选按名称（含标签）、日期或时间筛选；下面一行
  胶囊可以只看「7 天内」，或按某个标签筛。标题下面那行还会说明今年还有几个。
- **精确到分钟** —— 可以是「全天」，也可以指定到某时某分。
- **多标签、自定义颜色** —— 标签不限个数；颜色在编辑页用色相条调，不指定就用主题色。
- **倒数日详情** —— 点卡片进入：年月日时分秒的完整拆分，以及置顶开关、日期、时间和标签。
- **日历** —— 手写月历，一天有多个倒数日时最多显示三个圆点；点一天，那天的倒数日列在下方，
  同样能搜索和排序。
- **快速翻月** —— 点月份标题弹出年月选择窗，可一步回到本月，也能 ±1 年、±10 年翻页。
- **长按卡片** —— 直接置顶、编辑或删除，不必先进详情页；删除前会先确认。
- **一键添加多个** —— 新建时填上间隔天数和个数，一次添加一串同名、同标签、同颜色、同时间的
  倒数日；添加前会告诉你有几条、最后一条落在哪天。
- **桌面小组件** —— 两种：**单个**把一条倒数日放到桌面、时分秒实时跳动；**清单**列出接下来
  要数的几条。都随尺寸调整，都不需要任何权限。
- **外观** —— 大圆角卡片配 1px 细描边、超大的天数层级。主题有白、黑、青绿、雾蓝、暖橙、玫瑰，
  外加自定义色相；「白」是纯白底配接近黑色的强调色，「青绿」保持暖纸底，其余几套的页面、
  面板和描边都跟着主题色明显变化。配色固定，不跟随系统深色开关，也不从壁纸取色；秒数可以
  关掉，倒计时只走到分钟。
- **中英双语** —— 跟随系统语言，也可以在侧边栏手动选；日期格式一并切换。
- **备份与恢复** —— 把全部倒数日，以及外观、排序和语言设置导出成一个文件，也能读回来。
  导出可加密码（AES-256-GCM 加密）；导入先验密码，再选「覆盖」或「合并」，并会先告诉你
  会新增、覆盖或丢弃几条。另有一个「导出日历文件」，写成 .ics 交给系统日历。
- **更新日志 / 项目介绍** —— 侧边栏里按版本列出历次改动，当前版本会标出来；项目介绍就在
  应用内，含可复制、可跳转的 GitHub 地址。
- **大字体** —— 标题栏、侧边栏和卡片都避开状态栏，并跟随系统字体缩放长高，不挤压文字。
- **不需要任何权限、不联网、无统计。** 单模块，运行时不依赖任何第三方库，`minSdk` 27。

## 一键添加多个

名字、标签、颜色和时间只填一遍。新建时打开「一键添加多个」，再填两个数：

- **间隔天数** —— 相邻两条之间差几天，1～3650 天。
- **个数** —— 除了上面选的日期，还要再添加几条相同的，1～100 条。

上面选的日期**本身也会添加一条**，之后每条都比前一条多间隔那么多天。所以 10 月 14 日新建
「打副本」、间隔填 2、个数填 3，列表里就会出现 10 月 14、16、18、20 日共 4 条。

时间那一栏选的值，这一串里每一条都跟着走；全天就是全天，09:30 就是 09:30。这些条目算同一批，
所以「按添加时间」排序时它们挨在一起，里面的先后仍按日期排。每一条都是独立的倒数日，之后各自
编辑或删除，互不影响。

## 倒计时的读法

目标是**所选日期当地时间的 00:00**；这条倒数日如果指定了某时某分，就以那个时刻为准。
这个时刻过去之后，同一套算法反向运行，标签从「还有」变成「已过去」；目标日当天显示的是
「今天已过」。

从最高位起，还没有开始计数的字段用短横线占位，所以一眼就能看出还剩多久：

| 剩余时间 | 显示 |
|---|---|
| 4 个月 11 天 6 时 30 分 15 秒 | `----年04月11日 06时30分15秒` |
| 2 天 30 秒 | `----年--月02日 00时00分30秒` |
| 3 年 4 个月 11 天 6 时 30 分 15 秒 | `0003年04月11日 06时30分15秒` |

年、月、天按日历算，小时、分、秒按流逝时间算，所以夏令时切换的那一天仍然算一整天，
哪怕它实际只有 23 或 25 小时。

## 桌面小组件

长按桌面空白处 → 添加小组件，里面有两个可选：

**倒数日 · 单个** —— 再挑一个倒数日（列表里带时间，同名的两条不会挑混）。默认 4×2，拖大拖小
会自己换排版：拖扁了是「名字 + 天数 + 时钟」一行，拖大了再加上目标日期，并把天数拆成
「1年1个月4天」。点它直接打开这条倒数日。填了具体时间的倒数日，它也按那个时刻算，并在日期
那行写出时间（窄排版写在天数后面），和详情页一致。秒针由系统自己走，不额外唤醒应用。

**倒数日 · 清单** —— 不用挑，它自己列出接下来要数的几条，从近到远，一行一条；点哪一行就
打开哪一条。填了具体时间的会写成「今天 09:30」。默认 4×2 放得下三行，拖高了最多四行，
行会撑满整个组件；没有要数的日子时显示一行提示。

两个都**不需要任何权限**。

## 编译

需要：

- JDK 17
- Android SDK Platform 37 和 Build Tools 36.0.0
- 在 `local.properties` 里写好 SDK 路径，或导出 `ANDROID_HOME`

```bash
./gradlew testDebugUnitTest   # 单元测试
./gradlew assembleRelease     # APK -> app/build/outputs/apk/release/
```

Windows 下使用 `gradlew.bat`。

## 隐私

TickCount 只在自己私有的 `SharedPreferences` 中保存一份倒数日列表——日期、名称、时间、
标签、颜色、置顶和添加时间——此外没有别的东西。颜色是每个倒数日自己的颜色，用来在日历
和列表里区分它们。桌面小组件另有一份 `tickcount_widgets`，只记录「哪个小组件显示哪一条
倒数日」；主题、排序和语言存在 `tickcount_settings`。三份都在应用私有目录里，都不会自己
离开设备。

「数据管理」里导出的备份文件写到哪里由你选，加不加密也由你定，应用没有任何办法把它送出去。
它不声明任何权限，不发起网络请求，不含统计与广告。项目介绍里有一个指向本仓库的链接，
点击后在浏览器中打开——TickCount 自己没有联网能力，也没有 `INTERNET` 权限。
这些数据仅在 Android 自身的云备份开启时才会离开设备，而这由 `res/xml/backup_rules.xml` 决定。
